# ADR-0004 · 已发布文章的配图删除是有意的

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

articles 仓里若干文章的图片显示为 deleted，git status 会出现删除记录。
看起来像误操作。

## 裁定

**删除是有意的收尾动作。** 不要 restore，也不要用 `git add -A` 把它带回来。
文章发表后，配套插图不再需要随仓库保留。

## 后果

归档基线（仍被跟踪的产物）里不包含这些 PNG，所以「重跑生成器后工作区必须为空」
这条断言要按当前跟踪清单判定，被删掉的图重跑后重新出现在工作区属预期，
遇到时要按本 ADR 判断该删还是该留，不要机械地全量提交。
术语对应 [GLOSSARY-engineering-process.md](../../GLOSSARY-engineering-process.md) 的
「归档基线」。
