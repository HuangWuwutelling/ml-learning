# ADR-0002 · 三个主项目降级但不停用

- 状态: accepted
- 登记日期: 2026-11-01
- 决策日期: 2026-09-21

## 约束

`环境法律法规智能问答系统/`（RAG）与 `projects/env_agent/`（Agent）自 2026-08-04 起
不再继续开发、不再新增文章。但这两个项目是简历上的 RAG 与 Agent 两个主项目，
会被面试追问。

## 裁定

**「降级」= 停止开发，不等于不能用，不等于不进简历，不等于不进面试稿。**
简历上三个大模型应用项目（RAG / Agent / 微调）并排展示，不设主旗舰结构。
2026-09-21 起取消了「从三个里挑一个旗舰」的做法。

## 后果

简历叙述要同时交代「做到哪一步」和「现在的维护状态」两件事，否则面试现场会被当成半途而废。
演示时也要说清这是收敛过的项目，不是随手做的玩具。术语对应
[GLOSSARY-ai-application.md](../../GLOSSARY-ai-application.md) 的「降级」。
