# ADR-0005 · 已定稿项目不主动运行

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

三个简历主项目已定稿。它们的依赖不轻：env-rag 的 chromadb==0.5.5 与 gradio 6.x 冲突，
要另开独立 venv；lora_finetune 要 GPU；env_agent 要 API key 与网络。
每次跑一遍的代价不低。

## 裁定

**代码保留，不主动跑。** 只有演示或复现时才启，命令统一从仓库根 `ml-learning/` 运行，
完整命令写在 README 的「快速复现」一节。

## 后果

复现成本留在用户与面试者一侧，所以那一节必须写清依赖、前置条件和预期耗时，
不能只给一条 `pip install`。反过来，不能为了「跑得通」就在没装依赖的情况下
改业务代码绕过去。
