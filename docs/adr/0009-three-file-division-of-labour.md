# ADR-0009 · README / CLAUDE.md / plan.md 三文件分工

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

三份文档内容容易互相重复，改一处忘另一处，结果是三处说法不一致。

## 裁定

| 文件 | 职责 | 可见性 |
|---|---|---|
| `README.md` | 公开索引：已发文章、怎么跑 | 上 GitHub |
| `CLAUDE.md` | 干活的约定与坑 | 本地（被 gitignore） |
| `_local/plan.md` | 本机唯一事实源：进度、待写清单、变更记录 | 本地（独立 git 仓） |

三份不互抄正文，交叉引用只写路径。

## 后果

同一件事只在一处维护，改动范围可控。README 会出现在 GitHub 上，
所以里面不能出现本机求职信息、公司名、客户名。
