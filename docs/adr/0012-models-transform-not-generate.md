# ADR-0012 · 模型只做口径转换，不产生新数据

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

`models/sediment_cd_attribution.py` 这类脚本容易滑向「脚本算出来的就是结论」。
env/26 的核查里出现过把换算结果说成新发现的情况。

## 裁定

**脚本只做四件事：换参照系、换统计口径、换分级表、拆粒度。**
所有输入数字来自文献或标准，脚本不新增事实。

## 后果

每个数字都能追到源文。脚本输出的倍数差（例如完达山按 CF 与按 Igeo 算出的治理范围差
3.8 倍）必须写成「两个口径之差」，不能写成「新发现」。
术语对应 [GLOSSARY-environment-science.md](../../GLOSSARY-environment-science.md) 的
「CF（污染因子）」与「Igeo（地累积指数）」。
