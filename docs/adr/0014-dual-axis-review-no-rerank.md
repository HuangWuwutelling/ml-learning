# ADR-0014 · 双轴 review 不跨轴合并重排

- 状态: accepted
- 登记日期: 2026-11-01
- 决策日期: 2026-11-01

## 约束

一篇文章的**事实错误**（数字错、档名错、单位错）与**体例问题**（段落超长、重复、
图注缺失）混在一起时，如果合成一份报告，体例问题会把事实问题挤下去。

## 裁定

一次 review 拆成两条独立报告：

- **Standards 轴**：合不合本仓规范（写作约定、术语一致性、字数口径、图注规范）。
- **Facts 轴**：数字能不能回原文核，重点是单位、口径、分母。

两条轴各 ≤400 字，各自给出「本轴最严重的一条」。聚合时两个标题并列呈现，
**不合并、不跨轴挑一个「最严重的」**。派出的 subagent 用全新上下文，
prompt 必须自包含（把规范清单、来源清单整份贴进去）。

## 后果

报告总长会变长一点。换来的好处是事实错误的优先级不会被体例问题稀释，
这正是长 review 里最容易出问题的地方。
术语对应 [GLOSSARY-engineering-process.md](../../GLOSSARY-engineering-process.md) 的
「双轴 review」。
