# ADR-0008 · 文章数字以源文为准

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

核查轮次里出现过两类丢信息：按语感改写时把源文的信息删掉（例如源文写的是
`a Tl-specific mixed source`，改写后「混合」没了）；把精度压成标准档、把区间压成单值
（例如把 `0.110 mg/kg` 写成 `0.11`，把 `−0.36~−0.09‰` 压成一个数）。

## 裁定

**改「源文说 X」这类句子时，必须当场回原文 grep 原句核对。**
区间不许压成标准档；三处同步（正文、图、CSV）只算一致，不算核实。

## 后果

核查轮次会多花时间，改完还要再回原文看一遍。代价换来的是每个数字都能追到源文。
已发布文章改错了要发勘误节，这是这条 ADR 存在的原因。
