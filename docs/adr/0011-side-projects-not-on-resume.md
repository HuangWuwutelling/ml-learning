# ADR-0011 · 副线项目不进简历

- 状态: accepted
- 登记日期: 2026-11-01

## 约束

Rust 渐进式三阶段工具链、QMS 合规助手、土壤重金属可视化作品集 Demo 等副线项目
占了不少时间，但与目标岗位的主线不重合。

## 裁定

**副线项目不进简历正文，也不进 README 的项目索引。**
需要保留入口时，只留一句跳转说明（指向独立仓库或本机路径）。

## 后果

简历聚焦，面试时间不会被打散。副线代码的价值只能通过它自己的独立 README 体现，
不要为了在简历里显得多而加进去。另外，副线项目里涉及的公司名、客户名一律不得出现在
任何会上 GitHub 的文件里，包括本仓的术语表与 ADR。
