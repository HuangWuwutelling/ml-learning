# ADR-0001 · 文章没有官方源就不放

- 状态: accepted
- 登记日期: 2026-11-01
- 决策日期: 2026-10-02

## 约束

文章发在公开公众号上，读者会拿着数字去核。env/23 等文章里出现过两类没有源的内容：
`[E]` 估算值，以及社论性定量推论（例如「输在主路」这类没有测算依据的量化判断）。

## 裁定

没有官方源（标准、论文、政府或机构页面）的数字，**整句删除**。如果换成有源的口径
（`[S]` / `[L]`）能救回来，就换；救不回来就删段。不给「据估算」「业内普遍认为」
这类措辞留位置。

## 后果

文章的细节密度会下降，篇幅会变短，这是预期代价。核查轮次里可能把已经写好的段落整段删掉，
不要为了少删而放宽标准。术语对应
[GLOSSARY-publishing-pipeline.md](../../GLOSSARY-publishing-pipeline.md) 的「无官方源不放」。
