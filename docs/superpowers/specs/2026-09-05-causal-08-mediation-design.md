## 背景

07 篇（DAG+PSM）已交付：剥离社会信任 W 这一 confounder 后，"上网频率 X"对"互联网作为主要信息源 Y"的因果效应从朴素 +0.694 落到 Backdoor +0.393。但 07 第五节留了两个开放问题：

1. **算法持续升级**打破"X 是稳定处理"假设（DID 思路，02/06 已覆盖）
2. **用户自适应**打破"Z 是先于处理的外生变量"假设——长期高强度上网者改变了自身特征（年龄增长、习惯固化），Z 本身被 X 影响（**mediation 分析**处理）

08 是 07 的自然后续：把 07 剥离 confounder 后的"真实因果效应 0.393"再拆成**直接效应 + 间接效应**两条路径，回答机制问句"中间发生了什么"。

数据复用 CGSS 2023（07 已下载 + 清洗），新增 mediator 候选 **a285 互联网使用强度**（CGSS 2023 现有题项"过去一年您对以下媒体的使用情况-互联网"，5 级 Likert）。

方法：经典 Baron & Kenny 1986 三步法 + Sobel 1982 检验（不引入 VanderWeele NDE/NIE 现代框架，保持公众号读者门槛）。

> 从上网频繁到把互联网当主要信息源，中间发生了什么？

- 副：把因果效应拆开看：上网本身 vs 互联网使用强度，谁贡献更大

### 2. 5 节骨架（Story-led，方案 B）

| 节 | 标题 | 核心论证 |
|---|------|---------|
| 一 | 两组互联网依赖差多少？ | 现象对比：高强度上网组 ~85% 把互联网当主要信息源，低频组 ~18%；差距 0.67 朴素；引出机制问句 |
| 二 | 机制假说：X → a285 互联网使用强度 → Y | 6 节点 DAG（新增 M'）；解释为什么 a285 是 mediator 候选（X 增 → 互联网使用强度增 → 互联网作为信息源更合理）；与 07 的 collider M (a36) 对比 |
| 三 | Baron & Kenny 三步法：把总效应拆成直接 + 间接 | 三步回归模型；三组系数含义（c_total、a、c'、b）；间接效应 IE = a × b；Sobel 检验公式；与 07 PSM 的角色对比（07 剥离 confounder，08 把真实效应再拆） |
| 四 | CGSS 2023 实证拆解（n=5734） | 三步回归结果；**第二步 c_total 应等于 07 Backdoor 0.393（文章核心校验点）**；第三步 c'（直接）+ b（间接路径）；IE = a × b；Sobel Z 值 + p；bootstrap CI（稳健性）；拆解占比 |
| 五 | 机制答案 + 边界 | 回到机制问句；边界 1：a285 是否真的是 mediator（也可能部分承担 W 的混淆）；边界 2：CGSS 横截面 → 无法验证 X→M' 与 M'→Y 的时序；边界 3：a285 不一定是唯一 mediator |

### 3. 6 节点 DAG 扩展（07 的 5 节点 + 新增 M'）

```
07 的 5 节点 DAG:
  X ────────→ Y
  ↑    ↑
  │    │
  Z    W (后门)
  ↓
  M (collider, a36)

08 的 6 节点 DAG:
  X ─→ M' (a285) ─→ Y
  ↑    ↑                ↑
  │    │                │
  Z    W ────────→ Y ─┘ (W 后门到 Y 和 M')
  ↓
  M (a36, collider, 退到旁边)
```

**路径类型表**：

| 路径 | 性质 | BK 步骤 |
|------|------|---------|
| X → Y | 主路径（直接） | 第三步 X 系数 = NDE |
| X → M' → Y | 中介路径 | 第一步 a × 第二步 b = NIE |
| X ← Z → Y | 后门 | 控制 Z |
| X ← Z → M' | 后门 | 控制 Z |
| X ← W → Y | 后门 | 控制 W |
| X ← W → M' | 后门 | 控制 W |
| X → M ← Y | collider（M 在 07 已讨论，08 保留标注但不调整） | 不控制 |

**为什么 a285 是 mediator 而不是 confounder**：
- 时序上：先有 X（空闲时间上网频率）→ 后有 M'（互联网使用强度整体感受）→ 后有 Y（判断信息源）
- a285 与 X 相关但不被 X 完全决定（还包含工作、学习、社交等使用），所以不是 collider
- a285 与 W (社会信任) 可能相关，但不构成 X ← a285 → Y 的后门结构（a285 不是 X 的上游）

### 5. Baron & Kenny 三步法 + Sobel 检验

**第一步**：M' ~ X + Z + W（OLS）
- 输出：a（X 系数）、SE_a
- 含义：高强度上网组在控制了性别、年龄、社会信任后，互联网使用强度平均比低频组高多少
- **预期**：a ≈ +0.5 ~ +1.0 Likert 单位（量级）

**第二步**：Y ~ X + Z + W（OLS）
- 输出：c_total（X 系数）
- **核心校验**：c_total **应严格等于 07 Backdoor 的 +0.393**（因为第二步与 07 回归方程完全相同）
- 如果不等，立即排查（mask 对齐？Z/W 编码方式？）

**第三步**：Y ~ X + M' + Z + W（OLS）
- 输出：c'（X 系数 = **NDE 自然直接效应**）、b（M' 系数）
- 含义：控制 M' 后，X 对 Y 的剩余直接效应；M' 对 Y 的效应
- **预期**：c' 显著小于 c_total（如果 a285 是真 mediator）；b > 0（互联网使用强度越高，越倾向把互联网当信息源）

**间接效应 IE** = a × b
- **预期**：IE > 0 且显著（占 c_total 的 X%）

**Sobel 检验**：
- SE_IE = sqrt(b² × SE_a² + a² × SE_b²)
- Z = IE / SE_IE
- p 值（双侧）

**Bootstrap CI**（稳健性）：
- 1000 次重抽样，每次跑完整三步 + 计算 IE
- 取 IE 的 2.5% 和 97.5% 分位数作为 95% CI
- 如果 bootstrap CI 不含 0，与 Sobel p < 0.05 互相印证

### 6. 与 07 数字的横向对比

| 估计 | 来源 | 数字 | 含义 |
|------|------|------|------|
| Naive Y ~ X | 07 | +0.694 | 不控制任何 confounder |
| Backdoor Y ~ X + Z + W | 07 / 08 第二步 | **+0.393** | 总效应（剥离 confounder 后） |
| 朴素 Y ~ X | 07 PSM | +0.561 | ATT（处理组平均处理效应） |
| NDE Y ~ X + M' + Z + W | 08 第三步 | 预期 +0.1~0.3 | 直接效应（剥离 mediator 后） |
| NIE a × b | 08 计算 | 预期 +0.1~0.3 | 间接效应（通过 a285 互联网使用强度） |
| NDE + NIE | 08 验算 | 应 = +0.393 | 拆解恒等式 |

**关键校验**：NDE + NIE 应该 = c_total = +0.393（拆解恒等式）。如果不严格等，是 OLS 拟合残差造成，可接受 0.001 量级偏差。

### 7. 关键风险点 + 应对

**风险 1：a285 真的是 mediator 吗？**
- a285 与 X (a3012) 都关于"上网"，理论上时序可能反（先大量使用互联网 → 才意识到自己上网频繁）
- a285 也可能与 W (社会信任) 相关，承担部分 W 的混淆
- **应对**：第四节先跑主结果，第五节讨论。如果 c' 仍显著（partial mediator），如实说明。

**风险 2：Sobel 检验的渐近正态假设**
- IE 分布偏态，n=5734 渐近正态近似尚可但不严谨
- **应对**：Sobel p 之外报告 bootstrap CI（1000 次重抽样）作为稳健性证据。

**风险 3：c_total ≠ 0.393**
- 07 的 0.393 来自同一回归方程，08 第二步应严格相等
- **应对**：如果不等，立即排查（mask 对齐？Z 编码？标准误报告方式？）

**风险 4：a285 与 a3012 的语义重叠**
- a3012 = "空闲时间"频率（行为层面）；a285 = "过去一年"使用强度（整体感受层面，含工作/学习/社交）
- 二者 corr 实测应在 +0.3 ~ +0.5 范围（既相关又不完全重合）
- **应对**：第二节解释为什么这两个不同（行为 vs 整体感受）；第四节报 corr 实测值

**风险 5：CGSS 横截面数据限制时序**
- X → M' 与 M' → Y 的因果方向不能从横截面数据直接验证
- **应对**：第五节作为边界讨论；引用 Pearl 2001 的因果定义（mediation 需要时序假设，CGSS 提供的是关联结构）

## 风险与回退

如果第四节跑出来 c_total ≠ 0.393 或 Sobel p > 0.05：
- 优先排查 mask 对齐（最常见 bug：每个变量单独 mask 后取 min）
- 其次排查 Z/W 编码（07 已确认 1/2 二元 + Likert 5 级）
- 如果以上都 OK 但数字不符，停下来与用户讨论，不强行发文章
