# DEMO CONTENT — AIAG CQI-11 特殊过程：电镀系统评估 (synthesized overview).

## 概述

CQI-11《电镀系统评估》（Plating System Assessment）是 AIAG 发布的特殊过程评估标准之一，适用于汽车行业供应链中对电镀过程（如镀锌、镀镍、镀铬、镀锡、镀铜、合金电镀、化学镀、阳极氧化等）的系统评估。CQI-11 与 IATF 16949 配套使用，是汽车供应链中对电镀供应商进行过程审核的重要工具。

## 适用范围

CQI-11 适用于所有汽车产品及其生产材料的电镀过程。标准从过程输入、过程控制、过程输出三个维度对电镀过程进行系统评估，关注镀液成分、工艺参数、镀层厚度、结合力、外观、耐腐蚀性等关键控制点。

## 核心评估要素

- 工艺文件完整性：作业指导书、PFMEA、控制计划应覆盖全部电镀工艺过程
- 镀液控制：主盐浓度、添加剂浓度、pH 值、温度应定期检测并记录
- 工艺参数稳定性：电流密度、电压、镀覆时间应连续监控
- 镀层质量检验：厚度、结合力、耐腐蚀性（如中性盐雾 NSS）应按批次检验
- 环保与职业健康：废水、废气应达标排放，操作人员应有防护装备

## 与召回关联

电镀层的失效（剥落、腐蚀、镀层质量不达标）会显著影响汽车零部件的使用寿命和可靠性，严重的会因批量腐蚀或连接失效触发汽车召回。CQI-11 旨在通过系统化的过程评估降低电镀相关的质量风险。
