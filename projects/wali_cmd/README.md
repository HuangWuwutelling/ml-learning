# 瓦力的命令行速查（wali_cmd）

微信小程序，命令行命令速查工具。

**项目位置**：本目录（`projects/wali_cmd/`）是**独立 git 仓库**，不推送到 GitHub，仅在本地做版本控制。

## 简介

个人使用的命令行速查工具，记录 Linux 与 Windows 常用命令（139 条），覆盖文件操作、文本处理、网络、进程管理、磁盘存储、压缩归档、系统信息、权限用户、软件包、实用工具等场景。

## 技术栈

- 微信小程序（miniprogram/）
- 微信云开发（cloudfunctions/）
- 云数据库：NoSQL，按 platform + category + subcategory 分层
