# 环保标准查询 MCP Server（GB 36600-2018）

把《土壤环境质量 建设用地土壤污染风险管控标准》（GB 36600-2018）的筛选值、管制值和
风险筛查判定，做成一个 MCP server，让 AI agent 查得到、查得准，而不是靠模型记忆编数字。

**没有模型参与判定。** 限值、条款、边界（等于 / 大于）全部来自标准原文，写成确定性规则，
每一条结论都能指回条款号。

## 解决什么问题

土壤污染这块，模型答「镉的第一类用地筛选值是多少」经常给错数；给了数也不说清是
「可以忽略」还是「要修复」。这个 server 把两件事分开：

- **查数**：`get_limits` 给出筛选值、管制值、CAS 号、条款号，附另一类用地的值备查
- **定档**：`screen_result` 按 5.3.2 / 5.3.3 / 5.3.4 / 5.3.5 给一个测值定性，并说明下一步该做什么

## 快速复现

```bash
pip install -r requirements.txt

# 起服务（stdio 传输，挂到 Claude Code / Claude Desktop 当 MCP server）
```

## 五个工具

| 工具 | 干什么 | 返回的关键字段 |
|---|---|---|
| `search_items` | 按名字片段找标准里的项目名 | `items`（含 CAS、分类、条款号）、`total_matched` |
| `get_limits` | 查某污染物在某类用地下的筛选值 / 管制值 | `screening_value`、`control_value`、`other_land_type` |
| `screen_result` | 给一个测值定档 | `tier`、`actions`（每条带条款号）、`exemption` |
| `screen_batch` | 一次判一批测值 | 逐条 `verdicts` + `worst_tier` + `tier_counts` |
| `get_background_value` | 查附录 A 的土壤环境背景值 | `background_value`、`tiers`（全部档位） |

### 三档结论与依据

| 档位 | 触发条件 | 依据条款 | 下一步 |
|---|---|---|---|
| `risk_ignorable` | 测值 ≤ 筛选值 | 5.3.2 | 风险一般可忽略 |
| `detailed_investigation` | 筛选值 < 测值 ≤ 管制值 | 5.3.3 + 5.3.4 | 开展详细调查（HJ 25.1 / 25.2），再做风险评估（HJ 25.3） |
| `control_or_remediation` | 测值 > 管制值 | 5.3.5 + 5.3.6 | 采取风险管控或修复；修复目标应低于管制值 |

外加一个**注①豁免**：测值超过筛选值但不超过本地块土壤环境背景值（3.6）的，不纳入污染地块管理。
给了土壤类型时，砷 / 钒 / 钴会自己去附录 A 查背景值；其余元素的标准里没有背景值，
工具会明说「注① 判不了」，不编。

### 用地类型

`land_type` 可以写「第一类用地」/「第二类用地」，也可以写 GB 36600-2018 4.1 里的用地类别名
（居住用地、中小学用地、医疗卫生用地、社会福利设施用地、社区公园、儿童公园 → 第一类；
工业用地、物流仓储、商业服务业、道路与交通、公用设施、公共管理与公共服务、绿地与广场 → 第二类）。
规划用途不明确的按第一类（5.3.1）。

**认不出来就报错，不猜。**「公园」这种分不清是社区公园（第一类）还是绿地与广场（第二类）的说法，
工具会要求写明是哪一类——用地类型选错，整套限值都会用错列。

## 数据来源

- **标准**：GB 36600-2018《土壤环境质量 建设用地土壤污染风险管控标准（试行）》，
  2018-05-17 批准、2018-06-22 发布、2018-08-01 实施
- **标准原文 PDF 不进仓库**（ADR-0020），仓库里是解析后的 `corpus/gb36600_limits.json`
- **抽取口径**：pypdf 两种提取模式交叉验证（行序模式定归属、列位模式定列位），
  每个条目的四个数都要在列位模式里按顺序对得上，对不上的条目列进 `cross_check.failed`，
  不让错位的数字进 JSON。当前 **85 个条目（表 1 基本项目 45 + 表 2 其他项目 40），
  交叉核验未通过 0 条**
- 细节（页码映射、动过手的地方）见 [`corpus/SOURCE.md`](corpus/SOURCE.md)

## 已知限制（Known Limitations）

- **只覆盖 GB 36600-2018 一本标准**，85 个污染物项目。HJ 25.x、GB 15618-2018、
  HJ 1209-2021 都没接。
- **背景值只有砷、钒、钴**（附录 A 只给了这三个元素）。其他元素的背景值按 3.6 由本地块自行确定，
  工具判不了注①，调用方要自己把本地块背景值当 `background_value` 传进来。
- **用地类型靠关键词归类**，只认 4.1.1 / 4.1.2 明确列出的类别名。GB 50137 的细分代码
  （如 A33 之外的自定义类别）认不出，会要求写明第一类还是第二类。
- **附录 A 的背景值是土壤类型分档的统计值**（如砷在水稻土是 40 mg/kg，在绵土是 20），
  不是地块实测值。真做项目要用本地块调查值。
- **PDF 原文不在仓库**，换机器要自己准备 GB 36600-2018 的 PDF 才能重建语料；
  只跑服务和评测不需要 PDF。
- **标准原文 PDF 的字体把「芴」映射成了 `䓛`（U+44DB）**，语料按 CAS 号 218-01-9 校正，
  原始字形保留在 `name_raw` 字段。
